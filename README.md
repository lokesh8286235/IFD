# IFD

India Food Delivery — AI-powered food discovery, comparison, and ordering prototype.

> Tell IFD what you want. We'll figure out the rest.

## Status

Frontend prototype built with Next.js, React, TypeScript, and Tailwind-style custom CSS. Current restaurant, pricing, coupon, and ordering-handoff data are mock/demo data.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Product direction

- Natural-language food requests
- Real-total price comparison
- IFD MAX cart optimization
- Top-3 recommendations
- Verified food intelligence
- Exact-item / authorized cart handoff
- Regional food understanding
